# Breakout Game

## Features
- Physics-based paddle with directional influence
- Save/Load high scores
- Combo system for bonus points
- 6 levels of bricks
- Game over and restart

## How to Play
- Arrow keys to move paddle
- Space to launch ball
- ESC to quit

## Technical Highlights
- OOP design with models/views separation
- Delta time for smooth movement
- JSON/Text file persistence
- Collision detection with rects
